## I. Most important correction: independence of numerical checks

The original `No54_v0.1_VERIFY_20261105.py` directly enumerates permutations for `3 <= n <= 9`; that is genuine independent finite evidence. For larger `n`, however, its `expected(n)` function **computes the asserted formula**, rather than independently counting pattern occurrences. Therefore values printed for `n=10,20,40,60,100,120` are not separate validation of the identity and must not be represented as such.

A fresh independent script, `No54_v0.1_INDEPENDENT_ATTACK_20261105.py`, computes the marked-321 counts for **every n=3..22**, with exact rational arithmetic, without direct permutations and without using the proposed closed EGF. ## II. Explicit attack on the circle transform

Set `u={x_j-x_{j+1}}`, `v={x_{j+1}-x_{j+2}}` and `x=x_j`, all in `[0,1)`. For fixed `u,v`, the three consecutive real values are `x`, `{x-u}`, `{x-u-v}`.

All interval endpoints below are a.e. distinct. A full case split is:

| Condition | Anchor x range | Consecutive pattern |
| --- | --- | --- |
| `u+v<1` | `0<x<u` | 132 |
| `u+v<1` | `u<x<u+v` | 213 |
| `u+v<1` | `u+v<x<1` | 321 |
| `u+v>1` | `0<x<u+v-1` | 123 |
| `u+v>1` | `u+v-1<x<u` | 231 |
| `u+v>1` | `u<x<1` | 312 |

The transformation `(x_1,...,x_n) -> (x_1,u_1,...,u_{n-1})` is a triangular integer transformation with invertible inverse on the torus; it preserves Haar/Lebesgue measure. Each anchor `x_j` remains conditionally uniform given the entire vector `u`. The class restriction is precisely the family of inequalities `u_i+u_{i+1}<1`, and the conditional weight for pattern 321 at marked position i is `1-u_i-u_{i+1}`. **Attack result: no discrepancy.**

## III. Independent verification of the marked EGF index shift

Let `m=n-1` be the number of circular differences. Selecting a marked adjacent pair of difference variables consumes **two** of these variables, and there are `n-3=m-2` remaining difference variables across its left and right extensions. If left length is `l` and right length `r`, then `l+r=n-3`. Each fixed marked configuration therefore appears with power `z^(l+r+3)=z^n`, giving **H(z)=z^3 J(z)**. The left/right transfer factors are `(U^l 1)(u)` and `(U^r 1)(v)` because the kernel `1_{s+t<1}` is symmetric. **Attack result: the factor `z^3` is correct.**

## IV. Verifying the analytic chain without coefficient matching

Define `U f(t)=integral_0^(1-t) f(s)ds`, and `F(z,t)=sum_(k>=0) z^k (U^k 1)(t)`. Then `F=1+z U F`, `F(z,1)=1`, and `F_t(z,t)=-zF(z,1-t)`, so `F_tt=-z^2 F`. The unique formal analytic solution is

`F(z,t)=A(z) cos(zt)-sin(zt)`, `A(z)=sec z+tan z`, with `F(z,0)=A(z)`.

The marked integral is

`J(z)=integral_(u>=0,v>=0,u+v<=1) (1-u-v)F(z,u)F(z,v)du dv`.

From `F(z,y)-1=z integral_0^(1-y) F(z,v)dv`, Tonelli/Fubini and rearrangement give

`z J = integral_0^1 (F(z,y)-1) [ integral_0^y F(z,u)du ]dy`.

Since `d/dy F(z,1-y)=zF(z,y)` and `F(z,1)=1`, the bracket is `(F(z,1-y)-1)/z`. Hence

`J = z^(-2) integral_0^1 (F(z,y)-1)(F(z,1-y)-1)dy`.

Using `F_t=-zF(z,1-t)`, `z integral_0^1 F(z,y)dy=A(z)-1`, and elementary integration by parts, the result is

`H(z)=z^3 J(z)=(A(z)-1)^2/2 -(A(z)-1)+z`.

The Riccati identity `A'=(A^2+1)/2` then implies

`H(z)=A'(z)-2A(z)+1+z = sum_(n>=3) (E_(n+1)-2E_n) z^n/n!`.

All series identities hold as formal power series or in an analytic neighborhood of zero. **Attack result: no faulty boundary condition, incorrect integral swap, or index shift found.**

## V. Adversarial numerical design and mutation checks

The independent finite checker uses the polynomial recurrence `F_(k+1)(t)=int_0^(1-t) F_k(s) ds` and the triangle-moment identity

`integral_(u,v>=0,u+v<=1) u^i v^j (1-u-v)du dv=i!j!/(i+j+3)!`.

Summing over all `l+r=n-3` directly computes `N_n(321)/n!`. This computation does not use the closed form `A'(z)-2A(z)+1+z` to obtain the marked count. The separately generated Euler numbers use `E(n,0)=0, E(n,k)=E(n,k-1)+E(n-1,n-k)`, so it does not share the original arithmetic recurrence.

- Baseline n=3: exact integral equals `1/6` and `N_3(321)=1`.
- Wrong local weight `u+v` would instead integrate to `1/3`, predicting 2 (rejected already at n=3).
- Wrong `z^2` shift predicts a spurious n=2 coefficient; wrong `z^4` shift predicts a different n=4 value (rejected).
- For every `n=3..22`, the valid integral equals `(E_(n+1)-2E_n)/n!` (PASS).

## VI. Remaining actual risks

1. **Novelty is not established.** OEIS **A000708** already contains the sequence `E_(n+1)-2E_n` and even its generating function `(1-2*cos(z))/(1-sin(z))`. Since `A=cos(z)/(1-sin(z))` and `A'=1/(1-sin(z))`, the proposed marked-occurrence generating function `H(z)` is precisely that known generating function plus the correction `1+z` for the first two terms. OEIS interprets the same sequence using quasi-alternating permutations and alternate runs; several antecedents date to André. The proposed new item is the identity connecting that sequence to **marked consecutive 321 occurrences in `Av_n(123,231,312)`**, plus the new asymptotic popularity of Class 12. A simple bijection to a known interpretation could make the insight less novel than hoped.
2. **Published literature coverage is incomplete.** Ehrenborg–Kitaev–Perry (2011), Section 7, treats the same class and integral-operator transformation but not the marked-321 statistic in the section checked. Hassler–Kirgizov's 2025 paper and the Oct 2026 arXiv update report Class 12 among the unsolved cases. This does not rule out a separate subsequent paper or an unindexed result.
3. **Independent external referee not yet obtained.** The above is an internally carried out adversarial mathematical audit, not a human referee report, and it must not be labeled human-peer-reviewed or new independent-model PASS.
4. **Normalization is n*|A_n|.** The original authors' equation (1.1) is `p_n/(n |A_n|)`; normalizing by `(n-2)|A_n|` changes finite values, but not the limits.
